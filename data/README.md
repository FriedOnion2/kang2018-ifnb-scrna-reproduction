# Data

## Source

Kang et al. 2018, GSE96583. See the top-level README for accession links.

## Layout

- `data/raw/` — downloaded raw count matrices (git-ignored).
- `data/processed/` — intermediate Seurat objects (git-ignored).

## Download & integrity check

```bash
bash scripts/01_download.sh
md5sum -c data/raw/md5sums.txt   # verify downloads
```

`data/raw/md5sums.txt` is generated by the download script and is committed so
that anyone can verify they got identical files.

> Note: raw matrices are hundreds of MB — do not `git add` them. They are
> excluded via `.gitignore`. Anyone can re-download them from GEO.
